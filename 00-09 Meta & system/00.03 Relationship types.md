# 00.03 Relationship types

The complete edge vocabulary. Every typed link in the vault must be one of these. Any edge not on this list is an error; extend the list only with user approval. Definitions and direction conventions below. See [[00.01 Conventions & Design]] for the rules on counterpart edges.

## 1. Contract references

Edges between provisions inside the contract layer. `references` targets are textual facts — record only references a reader would actually follow.

| Edge | Direction | Definition |
|---|---|---|
| `incorporates` | A → B | Provision A makes B part of itself by reference (e.g., an MOU incorporates an article). |
| `implements` | A → B | Provision A operationalizes or carries out B (e.g., a craft article implements a national provision). |
| `modifies` | A → B | Provision A changes the application of B (e.g., an MOU modifies an article). |
| `defines` | A → B | Provision A supplies the operative definition used by B. |
| `procedural` | A → B | Provision A supplies the procedure for the right/obligation in B. |
| `mentions` | A → B | A names B without importing, changing, or defining it. |

## 2. Contract counterparts

Edges between parallel provisions of the four national agreements (and, where sensible, MOU-level parallels). **Counterparts are typed judgments, never equivalence.** The string `same` is prohibited. Read both ends fully before writing the edge; unread targets are `unverified`.

| Edge | Definition |
|---|---|
| `analogous` | Both provisions address the same subject in materially the same way: same scope, eligibility, and remedy. |
| `parallel` | Both provisions address the same subject and are structurally aligned, but differ in craft-specific details that are not material conflicts. |
| `divergent` | The provisions differ in scope, eligibility, rate, or remedy — a real difference a member must know about. |
| `supersedes` | One provision displaces an earlier version (older note carries `status: superseded`; edges point forward). |
| `unverified` | The counterpart target exists but could not be fully read before writing. Always listed in the phase audit. |

## 3. Legal relations

Edges from the legal layer (ELM, handbooks, arbitration, statutes, cases, agency decisions) to contract provisions and to each other.

| Edge | Direction | Definition |
|---|---|---|
| `interprets` | authority → provision | The authority construes or settles the meaning of the provision. |
| `applies` | authority → provision | The authority governs or applies directly to the provision. |
| `clarifies` | authority → provision | The authority resolves a narrow ambiguity without changing the rule. |
| `distinguishes` | case → authority/provision | The decision limits or differentiates an earlier authority. |
| `overrules` | case → case | The decision displaces an earlier decision. |
| `cites` | authority → authority | The authority relies on the cited authority. |
| `supersedes` | authority → authority | The later authority replaces the earlier one. |
| `restates` | ELM/manual → contract provision | The ELM (or manual) repeats contract language without material change. |
| `diverges` | ELM/manual → contract provision | The ELM (or manual) states a rule that differs from the contract. The `note` field states the divergence in one line. Divergence is a finding, not an error. |
| `implements` | authority → provision | The authority operationalizes the provision (e.g., a handbook implements a contract obligation). |

## 4. Hub and navigation links (untyped)

Links from hubs and meta notes to notes (`## Related`, `## Sections`, `parent:`, `related_hubs:`) are navigation, not meaning — they carry no relation type. If a navigation link asserts a substantive relation, it is wrong: move the assertion into a typed edge.

## 5. Frontmatter shape

```yaml
references:
  - target: "[[NALC §8.4]]"
    type: defines
counterparts:
  - target: "[[APWU §8.5]]"
    relation: analogous
  - target: "[[NRLCA §30.1]]"
    relation: divergent
    note: "evaluated pay; no direct OT analog"
interprets:
  - target: "[[NALC §8.5]]"
    relation: restates
```

- Targets are wikilinks to in-vault notes (or `missing-source` stubs). The link must resolve; the audit checks this.
- `note:` is optional except on `divergent`/`diverges`/`unverified` edges, where it is required.
- Record the forward edge explicitly. Never rely on backlinks.
