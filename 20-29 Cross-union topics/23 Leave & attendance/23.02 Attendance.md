# Attendance

## Why this matters across crafts

Attendance is the subject the four contracts barely write and the ELM almost fully owns: the agreements fund and continue the leave program and set sick-leave charging rules, while the attendance-control machinery — the unscheduled-absence reviews, the restricted sick leave letters, the AWOL determinations — sits in ELM Subchapter 510, which the contracts adopt by reference. A steward chasing an attendance case is therefore working one contract clause and one manual, and this hub maps which is which.

## Divergences worth noting

1. **The contracts don't write an attendance program — the ELM does.** Every contract's attendance content is adoption-by-reference plus charging rules; the operative machinery (attendance reviews, restricted sick leave, AWOL) lives in ELM Subchapter 510, which is only core-transcribed ([[31.07 ELM 510 Leave\|ELM 510]]). Full transcription of ELM 511.4x is the priority follow-up for this hub.
2. **Rural sick leave charges in whole days** while the hourly crafts charge to the hundredth of an hour ([[NRLCA §10.3\|NRLCA §10.3]]).
3. **The ELM-510 adoption scopes differ** — by effect (NALC) or by excluded class (PSE/MHA) — which changes whose attendance rules the manual actually governs ([[NALC §10.2\|NALC §10.2]], [[APWU §10.2\|APWU §10.2]], [[NPMHU §10.2\|NPMHU §10.2]]).
