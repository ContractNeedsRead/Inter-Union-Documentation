# Bargaining Information

## Full text

<!-- p.361 -->
MEMORANDUM OF UNDERSTANDING
BETWEEN THE
UNITED STATES POSTAL SERVICE
AND THE
AMERICAN POSTAL WORKERS UNION, AFL-CIO
Re: Bargaining Information
Pursuant to the provisions of Article 31 of the National Agreement,
the Employer shall, on a biweekly basis, provide the Union with
an electronic file containing the following information on those in
the APWU represented bargaining units:
1.	SSN                     21. Enter on Duty Date
2.	 Last Name              22.	 Retire on Date
3. First Name (Full)       23. Layoff
4.	 Middle Initial         24. Occupation Code
5.	Address                 25.	 Pay Location
<!-- p.362 -->
6.	City                    26. Next Step Date
7.	 State                  27. Retiree FICA Code
8. ZIP Code                28. Gender
9. Post Office Name        29. Veteran Preference Code
10.	 PO State               30. Date of Birth
11. PO ZIP                 31. Life Insurance Code
12. PO Finance Number       32. Handicap Code
13.	 PO CAG                 33. Thrift Savings Plan (TSP) Status Code
14. Rate Schedule           34. TSP Deduction Amount
15. Nature of Action        35. TSP Deduction Percentage Amount
16. Effective Date          36. USPS EIN
17.	 Pay Grade              37. Duty Station Finance Number
18.	 Pay Step               38. Facility Type
19. Health Benefit Plan     39. BA Code
20.	 Designation Activity   40. Performance Cluster
The parties acknowledge that the USPS is currently providing
this information to the APWU on a biweekly basis and no
additional programming is needed. The information will
continue to be provided to the APWU without charge.

## Summary

Biweekly electronic file under Article 31 containing the 40 listed data fields (SSN through Performance Cluster) for APWU-represented bargaining unit employees, provided without charge; no additional programming is needed.
