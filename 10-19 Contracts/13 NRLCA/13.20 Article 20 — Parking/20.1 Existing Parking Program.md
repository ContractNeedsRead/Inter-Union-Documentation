# NRLCA §20.1 — Existing Parking Program

## Full text

<!-- p.96 -->
### Section 1. Existing Parking Program

The existing parking program will remain in effect.

## Summary

Freezes the existing parking program for the term. One sentence; the operative content lives in the program itself, with §20.3 adding the rural-carrier priority rule.

## Cross-union comparison

All four agreements carry a parking article preserving existing programs; the substantive differences are in the security and priority sections.
