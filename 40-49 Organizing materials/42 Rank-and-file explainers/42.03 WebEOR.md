# WebEOR User's Guide (Web End-of-Run data)

## Purpose

A steward-facing guide to WebEOR (Web End-of-Run), the web application that collects End-of-Run data from USPS Mail Processing Equipment (MPE) and provides it in report form. Stewards use it to verify how many tours machines actually ran — the tour-count evidence that exposes underreported staffing surveys, per the [[42.01 Labor Checklist]] workflow. The guide is USPS-produced (v1.1.62, September 29, 2023); distribution was authorized to USPS agencies.

## Content

### Overview (preserved from the source)

WebEOR provides End-of-Run (EOR) data to managers, supervisors, and postal technicians for evaluating, maintaining, and improving automated Mail Processing Equipment (MPE). Data collection is automated from three sources: (1) End-of-Run data from Integrated Data Services (IDS) — RBCS and AFCS machines, retrieved by the Data Collector Service at the St. Louis, MO NDC every 15 minutes; (2) End-of-Day data from RBCS/IPSS machines, retrieved at 2 a.m. daily; (3) End-of-Day data from machine readers (WABCR, AFCS, DBCS) via a Remote Computer Reader (RCR) host connection, sent every 15 minutes. Manual entry covers Carrier Piece Count (CPC) and Manual Parcel data. The EOR File Import utility replaces the Data Collector feature.

Supported machines: AFCS, AFSM-100, APPS, BCS, DBCS, MPBCS, MLOCR, NGDBS, OCR, SPBS, WABCR, plus RBCS machines (ICU/BCS as OSS, DBCS as OSS, MLOCR as ISS, IPSS, RCR).

The Report Generator produces three report types: On-Demand Machine Reports (any combination of machines at a facility, user-defined date range), Individual Machine Reports (single machine), and User Defined Reports (any combination of machines/facilities/areas, schedulable and emailable, PDF/Excel/CSV).

Access: any employee with permission and valid credentials, from any browser (IE 9+, Firefox 29+, Chrome 35+). Roles: Administrator (full access, user/equipment management, all logs), Manager (view all run data, create/run reports), Technician (assigned facilities, add/edit run data, individual machine reports), Read-Only, and IPTS User (IPSS production tracking data and IPTS reports). WebEOR auto-logs-out after 30 minutes of inactivity.

### Run information core (preserved from the source)

The EOR Viewer is the primary tool for run data: view end-of-run summaries for multiple machines, view detailed run information, filter by date/facility/machine type, add/edit/delete runs, print, and export. Import EOR files via the EOR File Import utility (.eor, .txt, .dat supported); the import result lists records processed, imported, and any errors. Summary columns: Run Number, Machine ID, Start/End Time, Duration, Pieces Processed, Throughput, Sort Program — color-coded status (green normal, yellow warning, red error), sortable by column header, exportable to Excel/CSV. The Detailed Run Information screen adds run header, statistics, performance metrics (actual run time, idle, fault, utilization), bin information, errors, and notes. Manually added runs are flagged in the database; edits are logged in the Manual Data Entry Log with original values preserved.

Filters: date range, facility, machine type, machine ID, sort program, run status (complete/incomplete/all). Report options include grouping by machine/date/sort program, sort order, summary vs. detailed output, and mail-class selection (First-Class, Priority, Standard, Periodicals, Package Services).

### The rest of the guide (preserved in the source file, summarized here)

The full guide continues with: CPC and Manual Parcel viewers; NGTC, PSS, and PASS viewers; Run Plan Comparison (up to 4 run plans side-by-side) and the Run Plan Viewer; User Defined Reports (filters, formats, schedules, delivery by e-mail/inbox); DBCS-specific reports; EOR File Scan reports; Individual Machine Reports; IPTS reports (seven standard reports: Actual to Projected Workload, Daily Performance, End-of-Day Upload, ILU, RBCS Consolidated, Snapshot, Daily Workload) and IPTS weekly/daily uploads; Machine Outage Reports and Outage Summary; Equipment hierarchy maintenance (facilities, equipment, machines, IDS connections); eight system logs (Activity, Database Transfer, Exception, Machine Outage, Machine Run, Manual Data Entry, User Login); the glossary; IPTS projected-workload viewing/editing; data retention policy (EOR/IPTS/CPC/Manual Parcel data 730 days; logs 365 days; generated reports 90 days); Machine Catalog and relocation/transaction functions; Usage Statistics; area/district/region/division/site/station mappings; machine and sort-program mappings; ULX and Manual Parcel-to-IDS mappings; downflow and FHP (First Handling Pieces) surveys and replays; and the Admin section (site users/groups, collector configuration, EDW export, AFT upload, process mode, holidays, mail levels, IDS connections). The complete text is preserved at the source file listed in the frontmatter.

## How to use with the vault

- Verify actual machine tours (tours per day, days per week) from EOR run data and compare them against the staffing survey's recorded tours — the core discrepancy the [[42.01 Labor Checklist]] workflow targets.
- Machine Outage Reports and the Machine Run Log support [[41.04 Failure to Provide Maintenance Coverage]] claims about equipment operated without coverage.
- Run data plus eMARS work records ([[42.02 eMARS User Guide]]) form the evidence package for [[41.05 Understaffing Sample Grievance]].
- The contractual hook for the staffing surveys this data tests is [[APWU Article 19 — Handbooks and Manuals]] via the MMO layer at [[32.15 Maintenance MMOs]].
