# APWU Step 1 Grievance Form (web tool)

## Purpose

A fillable APWU **Step 1 Grievance Form** web page the user built for the LaborChecklistProd project — a self-contained HTML file (with its own stylesheet) that produces a properly formatted Step 1 grievance.

## Content

The tool renders the Step 1 grievance fields (grievant, article/section cited, statement of facts, remedy requested, signatures) as a printable web form. The file lives in the archive at `_sources/LaborChecklistProd/Grievance Form.html` and opens in any browser.

## How to use with the vault

1. Fill the form with facts assembled through the [[42.01 Labor Checklist]] and [[42.05 Maintenance Staffing Strategy and Grievance Guide]].
2. The Step 1 rules it must satisfy are [[APWU §15.2|APWU Article 15, Step 1]] and the ladder in [[28.01 Grievance Procedure]].
3. Sample maintenance grievances with the same structure: [[41.01]]–[[41.05]].
