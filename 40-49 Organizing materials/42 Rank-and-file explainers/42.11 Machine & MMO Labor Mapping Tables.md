## Per-MMO labor lookup CSVs

The archive's `Mapping CSVs/backup_csv/` folder holds one CSV per MMO (e.g., `MMO-001-18-Labor-Lookup.csv`) with the `Operation (days/wk) → Total (hrs/yr)` staffing curve — the distilled numbers behind [[32.15 Maintenance MMOs]] and the [[42.09 Challenge eWHEP Staffing Package]] workflow.

## How to use with the vault

1. Find the machine by name or acronym above.
2. Open its MMO — the full PDF is in [[32.17 MMO Rubric Library — Index]]; the key staffing tables are compiled in [[32.15 Maintenance MMOs]].
3. Compare the MMO's hours against the eWHEP staffing package using [[42.09 Challenge eWHEP Staffing Package]] and [[42.05 Maintenance Staffing Strategy and Grievance Guide]].
