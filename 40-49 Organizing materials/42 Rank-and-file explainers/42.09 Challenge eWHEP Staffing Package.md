# Challenge eWHEP Staffing Package

## Purpose

The step-by-step method for challenging the Electronic Workhour Estimator Program (eWHEP) staffing package — the USPS program that estimates Maintenance Craft work hours and authorizes positions (current instruction: MMO-125-20). Adapted from Idowu Balogun's column in the May/June 2021 *American Postal Worker*, which drew on the Article 12 Impact Guide.

## Content

### Step 1 — Obtain the eWHEP

Submit a **written request** for:

> "In pdf format, a copy of the current/complete/authorized eWHEP staffing package for [installation or facility name], to include all forms and worksheets."

Specify the delivery method (email/thumb drive) and keep proof of submission and receipt of the Request for Information ([[42.06 Requests for Information]]).

### Step 2 — Verify the Mail Processing Equipment inventory

- **Section 2A (Miscellaneous Postal Equipment):** smaller/portable equipment (strapping machines, portable conveyors); hours set by the current MMO for each item.
- **Section 2B (Major Mechanization/Automation):** high-visibility equipment (DIOSS, APBS); **confirm the inventory counts match the physical machines** — six DIOSS machines must appear as six entries.
- **Worksheet 2C (Additional Requirements):** new equipment without MMOs, locally purchased items, and items whose updated MMOs aren't yet reflected in eWHEP.

### Step 3 — Analyze the eMARS staffing worksheets for operational tours

Check, per machine: days per week operated, tours per day, stackers per machine.

**The classic defect — tour underreporting:** management historically hand-entered tour counts; the software now auto-populates them and often underreports (a machine running three tours shown as one or two). This discrepancy was scheduled for national arbitration.

**Evidence to prove underreported tours:** employee statements, management interviews, machine runtime reports, and clerk/mail handler weekly schedules. Maintain regular documentation — challenges require substantial concrete evidence.

## How to use with the vault

1. Get the package with the RFI letter ([[42.06 Requests for Information]]).
2. Decode every machine entry with [[42.11 Machine & MMO Labor Mapping Tables]]; check the authoritative hours in [[32.17 MMO Rubric Library — Index]] and [[32.15 Maintenance MMOs]].
3. Run the full staffing framework before filing ([[42.05 Maintenance Staffing Strategy and Grievance Guide]]), then file through [[28.01 Grievance Procedure]] with the Article 38 staffing basis ([[APWU Article 38 — Maintenance Craft]]).
