# Labor Checklist (eMARS/eWHEP data-collection workflow)

## Purpose

A data-collection checklist and companion workflow for maintenance stewards fighting staffing disputes with management's own numbers. It tells you which eMARS reports to pull to document who is on which machine, what training they have, what work orders and PM routes exist, and where work was bypassed — the evidence base for the understaffing, staffing-package, and bypass grievances in [[41.01 Bypassing Sample Grievance]] through [[41.05 Understaffing Sample Grievance]].

## Content

### The checklist (as the author wrote it)

**eMARS has multiple sections; from the user manual these reports help us the most.**

**PM Route Listings - Active / Work Load Schedules - Daily:**
All tours. Which personnel are on which machines? At least the last two weeks; longer if you want to look at trends. Generally with less training, PMs should be allocated longer times — if you have been to no classes you get 30% more time, if you have been to the basics you get 20% more time, and if you have been to the full complement of classes [the full time]. Deliver by CSV/Excel if possible.

**Personnel Report:**
All current, active, or prospective maintenance positions. All reverted maintenance positions. Which personnel have been to which classes? Deliver by CSV/Excel if possible.

**Work Orders:**
By acronym and machine number. All work orders on every machine over the past year. Work orders would go on top of the calculated time from PM MMOs.

**EQR match report; PM Route Bypass; all Form 4774s for the past year; Reactive Activity Report; Reactive summary report.**

**The full pull list:**
- Personnel Roster & Status (Excel)
- All reversions
- Training Records - By Employee (Excel)
- PM Route Listings - Active Routes (Excel)
- Work Load Schedules by employee for past 2 weeks (Excel)
- PM Route Bypass Report for past year (Excel)
- Work Orders by Acronym, Machine Number and the Employees who did the work for past year (Excel)
- Reactive Activity & Summary for past year (Excel)
- Form 4774 Breakdown Reports for past year (Excel)
- EQR Match Report (PDF)

### The workflow (from the author's video script)

The author's "eWHEP Staffing Package Project" script frames the strategy: management has systematically understaffed facilities using faulty eWHEP data — underreported machine tours (a machine running 3 tours recorded as 1–2 directly reduces calculated staffing), manual-entry manipulation, and no transparency. The four-part response:

1. **Machine Checker** — analyzes individual machine staffing requirements against MMO lookup tables.
2. **WebEOR Data Visualizer** — processes operational data to show actual machine usage (tours per day, days per week).
3. **RFI Builder** — generates legal requests for information (see [[42.06 Requests for Information]]).
4. **Grievance Form** — creates grievance documentation from the imported reports.

The contract theory: [[APWU Article 19 — Handbooks and Manuals]] violations (MMO-125-20 compliance is mandatory), hour-for-hour remedies for bypassed work, and prospective relief to fix the system — all arbitrable on objective, verifiable numbers. The author's limitations note: the tools are only as good as the input data, USPS may change report formats, and management may restrict access — so use multiple data sources and enforce access through the contract.

## How to use with the vault

- Pull the reports through [[42.02 eMARS User Guide]] (PM Route Bypass, Work Load Schedules, Work Orders, Form 4774) and pair them with the staffing survey.
- Feed the output into [[41.05 Understaffing Sample Grievance]] (below-complement) or [[41.01 Bypassing Sample Grievance]] (bypassed PM), and cite [[32.15 Maintenance MMOs]] (MMO-125-20) as the Article 19 document.
- For the underlying staffing/authorization framework, see [[42.05 Maintenance Staffing Strategy and Grievance Guide]].
- WebEOR usage data for tour-count verification: [[42.03 WebEOR]].
